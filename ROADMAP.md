# 🚀 Project Roadmap

The vision of the **CN E-commerce Expert** is to become the ultimate AI-driven copilot for Chinese e-commerce operations. Here is our plan for the upcoming quarters:

## Q4 2026
- [x] Basic prompt engineering for Taobao, Douyin, and Xiaohongshu.
- [x] Release standalone Python CLI for automated API calling.
- [x] Support **Batch Processing** for massive scale SKU optimization.
- [ ] Add explicit support for Pinduoduo (拼多多) algorithmic insights.

## Q1 2027
- [ ] **Graphical User Interface (GUI)**: A simple web dashboard (built with Streamlit or Gradio) for non-technical users to utilize the Python scripts without the command line.
- [ ] **Data Scraping Integration**: Allow the agent to automatically scrape competitor listings via URL before generating the plan.
- [ ] Multi-agent Workflow: Introduce a secondary "Copywriter Agent" dedicated solely to creating short-video scripts (抖音/视频号).

## Q2 2027
- [ ] Provide open-source fine-tuning datasets for open models (Llama/Qwen) based on highly converting e-commerce copy.
- [ ] Integration with major ERPs via API.
