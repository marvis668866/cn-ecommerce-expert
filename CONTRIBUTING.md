# Contributing to CN E-commerce Expert

First off, thank you for considering contributing to CN E-commerce Expert! It's people like you that make the open-source community such a fantastic place to learn, inspire, and create.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug in the source code or templates, you can help us by [submitting an issue](#).

### 2. Suggesting Enhancements
We are always looking for new ideas to improve the prompts or scripts! If you want to add a new platform (e.g., Pinduoduo, Xianyu) or improve existing SOPs, feel free to submit a feature request.

### 3. Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code, add documentation and ensure the script runs properly.
3. Update the `README.md` with details of changes if necessary.
4. Issue that pull request!

## Code of Conduct
By participating in this project, you are expected to uphold a welcoming and professional environment for all contributors.
